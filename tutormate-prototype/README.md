# TutorConnect prototype

Prototype frontend độc lập cho nền tảng kết nối gia sư và học sinh, viết bằng HTML, CSS và JavaScript thuần. Không cần cài package.

## Mở dự án

Mở `index.html` bằng trình duyệt hoặc phục vụ thư mục này qua bất kỳ static server nào.

## Các luồng đã có

- Màn hình đăng nhập hiện đại với lựa chọn nhanh vai trò để trải nghiệm demo.
- Đổi không gian **Học sinh / Gia sư / Quản trị viên** từ menu góc trái.
- Học sinh: khám phá gia sư qua bản đồ mô phỏng, bộ lọc, đặt lịch, lịch học, hỏi đáp, tin nhắn, tài liệu và thanh toán.
- Gia sư: tổng quan học sinh, nhận lớp, quản lý lịch rảnh, nộp CV, hồ sơ xác thực, tin nhắn và thu nhập/rút tiền.
- Quản trị viên: chỉ số vận hành, duyệt hồ sơ gia sư, quản lý lịch hệ thống, đối soát và duyệt chi trả.
- Các modal và trạng thái demo: đặt lịch, gửi tin nhắn, cập nhật CV, duyệt hồ sơ/chi trả, thêm lịch và hiển thị thông báo.

## Đưa vào production

Đây là bản UI prototype. Để vận hành thực tế, cần bổ sung API/backend, xác thực phân quyền, cơ sở dữ liệu, lưu tệp CV, bản đồ thật (Mapbox/Google Maps), chat realtime, lịch đồng bộ, cổng thanh toán và quy trình KYC/kiểm duyệt.
